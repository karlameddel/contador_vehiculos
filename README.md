# Proyecto de Fundamentos de Sistemas Inteligentes (FSI)

> Proyecto desarrollado originalmente como práctica para la asignatura **Fundamentos de Sistemas Inteligentes**.

---

## 📌 Descripción

Este repositorio contiene un programa desarrollado de forma conjunta como una aproximación inicial y académica a los conceptos vistos en la asignatura. 

Se trata de una implementación básica orientada a resolver el problema planteado durante el curso. Es un código funcional pero sencillo, con un enfoque directo y con amplio margen de optimización.

## 🔮 Posibles Mejoras Futuras

Aunque el programa cumple con el objetivo académico inicial, existen múltiples vías técnicas de mejora y ampliación:

- [ ] **Optimización de algoritmos:** Migrar de búsquedas básicas o heurísticas simples a aproximaciones más eficientes (como $A^*$, algoritmos genéticos o poda alfa-beta, según proceda).
- [ ] **Refactorización y arquitectura:** Modularizar el flujo principal separando lógica de negocio, manejo de datos e interfaz.
- [ ] **Interfaz de usuario:** Añadir una interfaz gráfica (GUI) o web para visualizar el estado del sistema en tiempo real en lugar de operar únicamente por consola.
- [ ] **Manejo de casos límite y validación:** Implementar una suite de pruebas unitarias (`tests`) y robustecer la validación de entradas.
- [ ] **Paralelización / Rendimiento:** Evaluar optimizaciones en tiempo de ejecución o procesamiento concurrente si la escala de datos crece.
